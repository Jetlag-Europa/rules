# Jet Lag Community Rules

This repository contains a Starlight documentation site for master rules and game-specific rule documents.

## Commands

```bash
npm install
npm run generate:docs
npm run dev
npm run build
```

## Content

- `src/content/docs/master/latest/` contains the current master rulebook split into pages.
- `src/content/docs/master/v1.0/` is an archived snapshot that remains accessible by direct link and from the archive page.
- `src/content/docs/games/` contains permanent game-specific rule pages.
- `src/content/docs/templates/` contains copyable Markdown templates for new games.

The sidebar shows the latest master rules prominently. Older master versions remain published but are linked from `Master Rules > Archive`.
