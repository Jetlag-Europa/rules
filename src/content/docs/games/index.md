This section collects rules for specific community games.

Each game packet contains the local amendments, clarifications, map references, timing rules, and other details that only apply to that event. These pages are meant to sit alongside the [main rules](/main/), not replace them.

Over time, more game packets will be added here as new games are planned and documented.
